隐私政策

拾图（PicHarvest — Bulk Image Downloader）帮助用户收集、预览、筛选和批量下载网页图片。本政策说明扩展如何处理信息。

1. 处理的信息与用途

在用户点击扩展并使用收集或下载功能后，扩展读取所选来源页面的标题、网址、图片地址、文件名、尺寸及与图片下载相关的相册数据，用于展示图片、筛选结果、获取可用的大图地址和保存文件。扩展不会为了建立浏览档案而持续追踪用户访问的其他网页。

2. 本地存储

图片列表、来源页面信息、选择与下载记录，以及语言、筛选和命名等设置保存在浏览器的本地或会话存储中。扩展不将这些信息同步到开发者服务器，也不内置广告或使用情况分析服务。

这些本地信息可能保留至用户清除相关记录、清除扩展存储或卸载扩展。已保存的图片文件独立保存在用户的下载目录中，卸载扩展不会自动删除这些文件，用户可以自行删除。

3. 网络请求与第三方

预览、解析图片地址和下载时，浏览器需要访问来源网站、图片服务器或其提供的下载接口。这些服务可能接收 IP 地址、请求的图片地址及正常网络请求信息，并适用各自的隐私政策。扩展不会绕过来源网站的访问控制。

本隐私政策网页由 GitHub Pages 托管。访问本网页时，GitHub 可能按其隐私声明处理请求日志等信息。本网页不嵌入第三方分析或广告脚本。

4. 帮助与反馈

反馈功能打开用户的邮件应用，邮件由用户检查并主动发送。开发者只接收用户发送的邮件内容及随邮件提供的信息，用于答复和处理反馈；邮件服务商依照自身政策处理邮件。用户可以通过下方邮箱提出删除反馈邮件的请求。

5. 浏览器权限

  • activeTab：在用户操作后临时访问当前来源标签页。
  • scripting：运行扩展内置的脚本，读取图片信息并执行用户发起的滚动收集等操作。
  • downloads：保存用户选择的图片，并读取相关下载任务状态以展示进度和重试失败任务。
  • storage：保存本地设置和收集、下载记录。

6. 数据使用承诺

开发者不出售用户数据，不将用户数据用于与图片收集和下载这一单一用途无关的目的，也不用于信用评估或贷款。PicHarvest 对用户数据的使用和转移遵守 Chrome Web Store 用户数据政策，包括 Limited Use（有限使用）要求。

7. 更新与联系

如果扩展的数据处理方式发生变化，本政策将相应更新并注明更新日期。隐私问题或反馈请联系：dayelqpl@gmail.com。

Privacy Policy

PicHarvest — Bulk Image Downloader helps users collect, preview, filter and download images from web pages in bulk. This policy explains how the extension handles information.

1. Information processed and its purpose

After you activate the extension and use its collection or download features, it reads the selected source page's title and URL, image URLs, filenames, dimensions and album data relevant to image downloads. This information is used to display and filter images, resolve available larger image URLs and save files. The extension does not continuously track other pages you visit to build a browsing profile.

2. Local storage

Image lists, source page information, selections, download records and settings such as language, filters and file naming are stored in the browser's local or session storage. The extension does not synchronize this information to a developer server and includes no advertising or usage analytics services.

Local information may remain until you clear the relevant records, clear extension storage or uninstall the extension. Downloaded image files are stored separately in your download location. Uninstalling the extension does not delete those files; you can delete them yourself.

3. Network requests and third parties

Previewing images, resolving image URLs and downloading files require requests to source websites, image servers or their download interfaces. Those services may receive your IP address, requested image URLs and ordinary network request information, subject to their own privacy policies. The extension does not bypass source website access controls.

This policy page is hosted on GitHub Pages. GitHub may process request logs and related information under its own privacy statement when you visit this page. This page contains no third-party analytics or advertising scripts.

4. Help and feedback

The feedback feature opens your email application. You review and send the email yourself. The developer receives only what you send and the information accompanying your email, and uses it to respond to and address your feedback. Email providers process messages under their own policies. You may request deletion of feedback emails by contacting the address below.

5. Browser permissions

  • activeTab: Temporarily accesses the current source tab following your action.
  • scripting: Runs scripts bundled with the extension to read image information and perform user-initiated actions such as scrolling to collect images.
  • downloads: Saves selected images and reads the status of related download tasks to display progress and retry failed downloads.
  • storage: Stores local settings, collection records and download records.

6. Data use commitments

The developer does not sell user data, use it for purposes unrelated to the extension's single purpose of collecting and downloading images, or use it for creditworthiness assessments or lending. PicHarvest's use and transfer of user data comply with the Chrome Web Store User Data Policy, including the Limited Use requirements.

7. Changes and contact

If the extension's data handling changes, this policy will be updated with a revised date. For privacy questions or feedback, contact dayelqpl@gmail.com.
